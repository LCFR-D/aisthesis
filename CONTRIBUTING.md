# Contributing

1. Open an issue describing the visual failure, evidence class and expected acceptance condition.
2. Add or update a focused test before changing detector behavior.
3. Run `pytest -q` and `aisthesis --help`.
4. Keep measurements, multimodal observations and human acceptance separate in code and documentation.

Small, evidence-backed pull requests are preferred. By participating, you agree to follow `CODE_OF_CONDUCT.md`.

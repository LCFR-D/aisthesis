# LCFR frontend capability map

The public skill is standalone. These are the LCFR roles it consolidates, not runtime dependencies.

| Original role | Question owned | Bundled location |
|---|---|---|
| Metis | Mode, scope, product truth, authority, governance | `SKILL.md`, `methodology.md` |
| Brand System Development | Source truth, visual grammar, tokens, asset provenance | `design-and-brand.md` |
| Responsive Generated Brand Art | Breakpoint masters, paired modes, protected regions, image delivery | `design-and-brand.md`, `responsive-and-accessibility.md` |

| Performance | Loading, runtime, Core Web Vitals, asset delivery | `release-contract.md` |
| Code review | Security, logic, maintainability, regression and release readiness | `release-contract.md` |

## Standalone rule

An agent can execute the complete workflow using only this skill. Optional external skills may provide additional vocabulary or examples, but cannot override the brief, product evidence, accessibility, provenance, or release contract.

## Optional lenses not redistributed

The skill does not copy third-party skill text, templates, or protected examples. Separately installed, appropriately licensed design-review tools may advise a bounded question. Their output enters as optional evidence and is resolved through the authority order; no external lens is required to execute this stack.

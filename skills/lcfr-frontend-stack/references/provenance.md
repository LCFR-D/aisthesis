# Provenance

This standalone skill is an LCFR-authored consolidation of locally maintained LCFR frontend methods:

- Metis: scope, product truth, authority order, operating loop, and release governance;
- Aisthesis Visual Judgment: evidence boundaries and four-pass visual review;
- Kinetograph and Scrolltelling QA: exact progress, native-scroll verification, physical pacing, and reproducible frame evidence;
- Brand System Development: source-locking, semantic tokens, asset provenance, and paired modes;
- Responsive Generated Brand Art: breakpoint masters, protected regions, and responsive image delivery;
- LCFR release practice: dogfooding, accessibility, performance, independent review, preview parity, and production read-back.

The text and templates in this package were consolidated and rewritten for this public release under MIT. No third-party skill body, proprietary template, customer evidence, private product artifact, or generated asset is redistributed.

Optional third-party lenses named in `skill-map.md` are interoperability references only and are not dependencies or bundled content.
